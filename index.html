Step-by-Step Setup

1. Connect Knowpath to ChatGPT

Follow three simple steps to connect ChatGPT with the Knowpath Model Context Protocol (MCP) server. Once connected, ChatGPT dynamically accesses your real questions and learning history.

How ChatGPT Communicates with Knowpath
Architecture
1

Locate Connection Endpoints

Knowpath exposes a production-ready Server-Sent Events (SSE) endpoint conforming to the open Model Context Protocol standard.

MCP SERVER-SENT EVENTS (SSE)
https://bloomcommerce.space/mcp/sse

Message endpoint: https://bloomcommerce.space/mcp/message

2

Add MCP Server to ChatGPT

Configure the server in ChatGPT or your favorite MCP-compatible agent environment:

  1. Open ChatGPT Settings → Connected Apps (or Developer Mode).
  2. Select Add MCP Server.
  3. Name it Knowpath and paste the SSE URL above.
  4. Save and enable all requested tool capabilities.
Authentication: Ensure your user account is registered on bloomcommerce.space. Bearer tokens are provided automatically via Auth0 OAuth.
3

Verify Connection in ChatGPT

Send a quick verification prompt to ChatGPT to ensure it can reach Knowpath:

TEST PROMPT
Check my Knowpath connection and tell me my current interview mode.

Verification Checklist:

  • ✓ ChatGPT invokes get_current_mode tool
  • ✓ Returns active mode: SINGLE_TOPIC
  • ✓ Shows default topic: java-concurrency
Standard MCP Client Configuration Snippet
JSON Config

Using ChatGPT Desktop, Claude Desktop, Cursor, or Windsurf? Paste this configuration into your mcpServers configuration file:

mcp_config.json 
{
  "mcpServers": {
    "knowpath": {
      "url": "https://bloomcommerce.space/mcp/sse"
    }
  }
}
mcp_config_auth.json 
{
  "mcpServers": {
    "knowpath": {
      "url": "https://bloomcommerce.space/mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_KNOWPATH_AUTH0_TOKEN"
      }
    }
  }
}
The Practice Loop

2. How to Practice & Learn with ChatGPT

Experience realistic, high-signal technical mock interviews. Knowpath orchestrates the questions while ChatGPT conducts the interview and provides rigorous rubric evaluations.

The 4-Step Continuous Learning & Feedback Cycle
Practice Loop
1

Choose Interview Mode

Knowpath provides two tailored interview operating modes:

  • SINGLE_TOPIC: Focused deep-dive on one specific technology (e.g., Java Concurrency, PostgreSQL Optimization, Kafka Streaming, or Kubernetes).
  • COMPLEX_MULTI_TOPIC: Broad system engineering interview spanning architecture, concurrency, caching, and resiliency.
PROMPT EXAMPLE
Let's do a technical interview on Java Concurrency in Single Topic mode.
2

Receive Real Questions

ChatGPT triggers preload_questions to load verified questions from the database, then fetches the first question via get_next_question.

Questions include:

  • Realistic production context and requirements.
  • Expected trade-offs and complexity constraints.
  • Real edge cases that differentiate senior candidates.
PROMPT EXAMPLE
Preload 5 questions and give me the first question.
3

Answer & Get Rubric Evaluation

Provide your comprehensive technical solution. ChatGPT scores your answer and saves it via save_question_attempt with:

  • AI Evaluation Score: 1 to 10 scale assessing accuracy and architectural depth.
  • Candidate Confidence: 1 to 5 scale measuring your certainty.
  • Strengths & Gaps: Key edge cases missed, thread safety risks, or memory bottlenecks.

Your answer is instantly saved to your persistent history in the PostgreSQL database.

Identify Knowledge Gaps

Knowpath classifies every question to help you target what matters most:

  • ⚠️ Needs Improvement: Answers where confidence was low (≤ 3) or AI score did not meet senior standards (≤ 7).
  • 🚨 Critical Attention: Concept misunderstandings (score ≤ 5) or high uncertainty (confidence ≤ 2).

3

Targeted Weakness Retakes

Tell ChatGPT to practice only questions you previously struggled with:

GAP-FOCUSED PROMPT
Preload 5 questions from my knowledge gaps only and test me on them.

ChatGPT sets knowledge_gap_only = true in the preload_questions MCP tool, delivering immediate targeted practice.

Specification

Knowpath MCP Tool Reference

Overview of core tools registered on the Knowpath Model Context Protocol server.

Tool Name Description Key Parameters
get_topic Retrieve available interview topics, slug names, and tag taxonomies. page, size
get_current_mode Check user's active interview mode (SINGLE_TOPIC or COMPLEX_MULTI_TOPIC). None
set_interview_mode Switch between focused single topic and holistic multi-topic interview loops. mode, topicSlug
preload_questions Preload question sets with optional knowledge-gap filtering and topic scoping. limit, tags, knowledge_gap_only
get_next_question Fetch the next queued question for the current active interview session. sessionId
save_question_attempt Persist candidate response, AI rubric evaluation score (1–10), and confidence rating (1–5). questionId, aiScore, candidateConfidence, feedback
get_knowledge_gap_feedback Retrieve historical assessment data and AI feedback to isolate weak concepts. sessionId, topic, question
